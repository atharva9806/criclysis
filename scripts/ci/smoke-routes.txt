# Routes for scripts/ci/smoke.sh: the pages in docs/ARCHITECTURE.md §4.1 and
# the GET API routes in §4.2. POST /api/revalidate is checked separately.
#
# <route> | <expected text> | [<path that must exist, relative to the repo root> ...]
#
# The expected text (case-insensitive) must appear in what the page rendered,
# outside <head>, <nav> and <footer>, so neither the site navigation nor the
# page title can satisfy it. The texts hold for an import of
# fixtures/data-out-v1 (men's sample: Kohli, Sharma, Starc, Zampa, Anderson,
# Mishra; no teams or matches) and of the v2 fixture: generic headings for list
# pages, a player name for player pages, a JSON key or name for APIs.
#
# A route is skipped until its page or route handler exists. Routes that need
# v2 data (teams, matches, replays, models keyed by formatKey) also wait for
# fixtures/data-out, which the e2e job imports instead of data-out-v1 once it
# exists. Match 1384439 is the 2023 ODI World Cup final, India v Australia.
